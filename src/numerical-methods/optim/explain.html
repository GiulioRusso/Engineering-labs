Golden-section search

What you are looking at

Top left: the function, the current bracket [a, b] (orange) and the two inner points (green). Bottom right: every bracket so far, stacked downward, each 0.618 times the one above. Top right: the log of the bracket width, a straight line. Below: the centre of the bracket closing on the minimum.

To find the minimum of a function of one variable without derivatives, keep a bracket that contains it and two points inside. Compare f at the two points: the minimum cannot lie beyond the worse one, so cut that end away. Placing the inner points at 0.382 and 0.618 of the bracket, the golden ratio, makes the remaining inner point land exactly where the next step needs one, so every step costs a single new evaluation and shrinks the bracket by the same factor 0.618. It works for any unimodal function, even one with a kink.

$$c = b - \varphi(b-a),\quad d = a + \varphi(b-a),\quad \varphi = \tfrac{\sqrt5-1}{2} \approx 0.618,\quad \varphi^2 + \varphi = 1$$
  1. Evaluate f(c) and f(d).
  2. If f(c) < f(d) keep [a, d], else keep [c, b].
  3. One old point is reused; evaluate the one new point and repeat.

Worked example

A bracket of width 3: after 20 evaluations it is 3 × 0.618²⁰ = 2.0·10⁻⁴ wide. Each digit of accuracy costs log(10)/log(1/0.618) ≈ 4.8 evaluations.

Common mistakes

Using it on a function with several minima in the bracket: it converges to one of them, not necessarily the lowest.

Try it

Change the function to the kink: the bracket still shrinks by exactly 0.618 per step, since only comparisons of f are used.

A kink: no derivative needed

|x − 2| + 0.2x has no derivative at its minimum, which would stop Newton's method; golden-section search does not care.

−sin x: the top of a hill

Minimising −sin x is maximising sin x: the bracket closes on π/2.

Gradient descent and Newton's method

What you are looking at

Left: the contour map of f (dark = low) with the paths of the chosen methods from the start (bright dot). Top right: log f against iteration; bottom right: log |∇f|. Below: each method's distance to the minimum.

Gradient descent steps against the gradient, downhill, by a fixed fraction η. On an elongated bowl it is caught between two limits: η must be below 2/λmax or it overshoots the steep direction and diverges, yet along the shallow direction it then crawls. Steepest descent with a line search chooses the best step along the gradient each time; it never diverges, but on an elongated bowl it zig-zags at right angles, losing a factor ((κ − 1)/(κ + 1))² per step. Newton's method also uses the curvature (the Hessian H): it jumps to the minimum of the local quadratic model, in one step on a quadratic, and near any minimum it doubles its correct digits every step.

$$x \leftarrow x - \eta\nabla f, \qquad x \leftarrow x - \alpha^*\nabla f\ \ (\alpha^* = \arg\min_\alpha f), \qquad x \leftarrow x - H^{-1}\nabla f$$
  1. The elongation κ = λmax/λmin of the bowl decides how hard first-order methods find it.
  2. A fixed step is stable only for η < 2/λmax.
  3. Newton divides out the curvature: every direction looks the same to it.

Worked example

A bowl with κ = 50 from (2.4, 1.6): the line search loses only a factor (49/51)² = 0.92 per step and is still at f = 5·10⁻⁴ after 40 steps; a fixed step of 0.15 is above 2/50 = 0.04 and diverges; Newton lands on the minimum in one step. On Rosenbrock's valley from (−1.2, 1) Newton reaches the minimum in 5 steps.

Common mistakes

Raising the learning rate to go faster: past 2/λmax gradient descent does not go faster, it explodes. And Newton is not free: it needs second derivatives and a linear solve per step, which in many dimensions costs more than many gradient steps.

Try it

With the line search alone, raise κ from 1 to 100: the path turns from one straight step into a long zig-zag across the valley.

Round bowl (κ = 1)

The gradient points straight at the minimum: the line search and Newton arrive in one step, fixed-step descent on a straight line.

κ = 50: line search zig-zags

Each exact step ends where the new gradient is perpendicular to the old one: right-angle turns across a narrow valley, slow progress along it.

Step too big: gradient descent diverges

κ = 10, so the limit is 2/10 = 0.2; η = 0.21 overshoots the steep direction a little more each time and the path flies off.

Rosenbrock: Newton follows the valley

The curved valley floor defeats steepest descent, which bounces between the walls; Newton's quadratic model bends with the valley and reaches (1, 1) in a handful of steps.
