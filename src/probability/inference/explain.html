Confidence intervals

What you are looking at

Left: 60 repetitions of the same experiment (n measurements of a quantity whose true mean is 10). Each bar is that experiment's interval x̄ ± z·σ/√n; red bars miss the true mean. Right: how the width depends on the confidence level and on n.

From one sample we cannot know μ, but we can build an interval by a recipe that catches μ a known fraction of the time. Each new experiment gives a new interval; about 95% of 95% intervals contain μ.

$$\bar x\pm z_{1-\alpha/2}\,\frac{\sigma}{\sqrt n},\qquad z_{0.975}=1.96$$
  1. Compute the sample mean x̄.
  2. Its standard error is σ/√n.
  3. Go z standard errors each way.

Worked example

σ = 2, n = 10, x̄ = 10.4: 10.4 ± 1.96·0.63 = [9.16, 11.64].

Common mistake

"μ is in this interval with probability 95%." μ is fixed; it is either in or not. The 95% is about the method.

80%

Shorter bars, and about one in five misses.

n = 100

√10 ≈ 3.2 times narrower, still 95% coverage.

Hypothesis tests

What you are looking at

Top: the distribution of the test statistic if there is no effect (H₀, blue) and if the true effect is d (orange). The black line is the rejection threshold; the red area under the blue curve is α; the dashed line is an observed value. Bottom: the power against sample size.

A test fixes in advance how often we accept a false alarm (α) and rejects H₀ when the data would be too surprising under it. The p-value measures that surprise; the power is the chance of detecting an effect that is really there.

$$\text{reject }H_0\iff z>z_{1-\alpha},\qquad p=P(Z\ge z_\text{obs}\mid H_0),\qquad \text{power}=1-\Phi(z_{1-\alpha}-d\sqrt n)$$

Worked example

d = 0.4σ, n = 25: the orange curve sits at 2; with α = 0.05 (z > 1.645) the power is 1 − Φ(−0.355) ≈ 0.64.

Common mistakes

Reading p as P(H₀ true). Concluding "no effect" from a non-significant result with low power: absence of evidence is not evidence of absence.

n = 100

The orange curve moves to d√n = 4: almost always detected.

α = 0.01

The threshold moves right: fewer false alarms, but more real effects missed.
