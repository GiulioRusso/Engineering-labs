A loss does two jobs. Its minimum decides what the model converges to; its derivative decides how hard each example pushes, and whether training moves at all.

Squared, absolute and Huber

What you are looking at

Top: twelve points with one outlier and the straight line each loss fits (bold = selected). For the squared loss each residual is drawn as a real square — its area is the penalty. Bottom: penalty against residual for the three losses, with the points of the selected fit.
$$\ell_2=r^2,\qquad \ell_1=|r|,\qquad \ell_\delta=\begin{cases}\tfrac12r^2&|r|\le\delta\\ \delta(|r|-\tfrac12\delta)&|r|>\delta\end{cases}$$
  1. Squared: the gradient 2r grows with the residual, so one far point pulls as hard as many near ones. Its minimum is the mean.
  2. Absolute: every point pulls with force ±1, however far. Its minimum is the median: robust to outliers.
  3. Huber: squared (smooth, precise) near the line, absolute (robust) far from it.

Worked example

An outlier 8 units off contributes 64 to the squared loss — as much as 64 points 1 unit off. The squared fit tilts towards it; the absolute fit hardly moves.

Common mistake

Using squared error on data with occasional gross errors (sensor glitches, typos): one bad point ruins the fit.

Absolute error

The line follows the other eleven points.

Huber

Squares only for residuals within δ; beyond, the penalty grows linearly.

No outlier

With clean data all three lines coincide.

The sigmoid trap

What you are looking at

One example with true label 1 and a neuron that starts confidently wrong (z = −6, p ≈ 0.002). Top: the loss as a function of the score z for squared error (blue) and cross-entropy (orange), with each one's current position. Bottom: how z moves during training.

Squared error on a probability looks reasonable — its minimum is in the right place. But differentiate through the sigmoid and a factor p(1 − p) appears, which is almost zero when p is near 0 or 1. Exactly when the model is confidently wrong, it barely learns. Cross-entropy's derivative is simply p − y: largest when most wrong.

$$\frac{\partial}{\partial z}(1-p)^2=-2(1-p)\,p(1-p),\qquad \frac{\partial}{\partial z}(-\log p)=p-1$$

Worked example

At z = −6: the squared-error gradient is about −0.005; cross-entropy's is −0.998 — two hundred times stronger.

Common mistake

Training a classifier with MSE and blaming the learning rate for the plateau.

Softmax and temperature

What you are looking at

Top: four raw scores (logits). Bottom: the probabilities softmax makes of them; the true class in orange. Bottom plot: each probability as the temperature changes.
$$p_k=\frac{e^{z_k/T}}{\sum_je^{z_j/T}},\qquad \ell=-\log p_\text{true}$$
  1. Exponentiate (all positive), normalise (sum to 1).
  2. Only differences between scores matter: adding the same number to all changes nothing.
  3. T < 1 sharpens towards the largest; T > 1 flattens towards uniform.

Worked example

Scores (2, 1, 0.5, −1) at T = 1: p ≈ (0.57, 0.21, 0.13, 0.03). If class 1 is true, loss = −log 0.57 = 0.56.

T = 0.2

The biggest score takes nearly all the probability (used in sampling to be conservative).

T = 5

All classes nearly equal (used in distillation to show the "dark knowledge" between classes).

True class scored low

p_true ≈ 0.03: loss ≈ 3.5, a strong push.

One picture of every classification loss

What you are looking at

Top: each loss as a function of the margin m = y·f(x) (y = ±1): positive means correct, larger means more confident. Bottom: the value of each at your margin; bottom plot: their slopes.

What we actually want is the 0–1 loss — count the mistakes. But it is a step: zero gradient everywhere, nothing to follow. Every practical loss is a smooth stand-in above it.

$$\text{hinge}=\max(0,1-m),\quad \text{logistic}=\log_2(1+e^{-m}),\quad \text{exponential}=e^{-m},\quad \text{squared}=(1-m)^2$$

Common mistake

Squared loss rises again for m > 1: it penalises points for being too correct. Exponential explodes for m < 0: one mislabelled point dominates.

m = −1

A clear mistake: exponential e ≈ 2.7, hinge 2, logistic 1.9 — all pushing back.
