Steady-state error

What you are looking at

A unity-feedback loop following a step, ramp or parabola input: reference (dashed) and output, with the remaining error.

Feedback works by acting on the error. A plain proportional controller needs some error to keep pushing, so it never quite gets there. Every integrator in the loop (the "type") removes one level of error: type 1 follows a step perfectly, type 2 a ramp.

$$e_\text{ss} = \lim_{s\to 0}\frac{s\,R(s)}{1 + G(s)}, \qquad \text{step: } \frac{1}{1 + K_p}, \quad \text{ramp: } \frac{1}{K_v}, \quad \text{parabola: } \frac{1}{K_a}$$
  1. Type 0 on a step: finite error 1/(1 + K) — more gain, less error.
  2. Type 1 on a step: zero; on a ramp: a constant lag.
  3. Asking a type-0 loop to follow a ramp: the error grows without limit.

Worked example

Type 0 with K = 5: 1/6 = 17 % error. K = 20: 4.8 %. Add an integrator: 0 %.

Common mistake

Raising the gain to kill the error: it also pushes the loop toward instability (see the root locus).

More gain

A type 0 loop always leaves an error: some error is needed to keep pushing. With \(K = 20\) it shrinks to \(1/21\), about 5 %.

An integrator

A type 1 loop integrates the error: as long as any error is left, the push keeps growing. It only stops when \(e = 0\).

Following a ramp

The type 1 loop follows a moving target with a constant lag \(1/K_v = 1/K\): to keep moving it needs a steady error.

Type 0 and a ramp

Without an integrator the output cannot keep up with a moving target: the error grows without limit.

Type 2, parabola

Two integrators follow a steadily accelerating target with a constant error \(1/K_a\), here \(2/K\).

The root locus

What you are looking at

The path the closed-loop poles follow as the gain K grows from 0; the current poles are marked and the step response shown.

Closing the loop moves the poles. At K = 0 they sit on the open-loop poles; as K grows they move along fixed branches toward the zeros or off to infinity. When a branch crosses the imaginary axis the loop becomes unstable. The locus shows at a glance which gains give a good response.

$$1 + K\,G(s) = 0, \qquad \angle G(s) = 180^\circ\,(2k + 1)$$

Worked example

G = 1/(s(s + 1)(s + 3)): the closed-loop polynomial is s³ + 4s² + 3s + K. The poles from 0 and −1 meet at s = −0.45 when K = 0.63, then leave the real axis (oscillation). Routh: the loop is stable while 4·3 > K, so they cross the jω axis at K = 12, at ω = √3 = 1.73 rad/s. Above 12: unstable.

Common mistake

Assuming more gain is always more stable: for three or more poles it eventually destabilises the loop.

The poles meet

At \(K \approx 0.63\) the two slow real poles meet at \(s \approx -0.45\) (breakaway) and split into a complex pair: from here on the response overshoots.

Oscillatory

The pair moves up and towards the axis: less damping, more overshoot, but a faster rise.

On the edge

At \(K = 12\) the pair reaches the \(j\omega\) axis at \(\pm j\sqrt3\): the loop oscillates forever. The Routh criterion gives the same limit: \(4 \cdot 3 > K\).

Too much gain

Past \(K = 12\) the pair is in the right half plane: more gain made the loop unstable.

A zero helps

A zero at \(-2\) attracts one branch and bends the others away from the right half plane: the loop stays stable for much larger gains. This is what a lead compensator does.

Two poles

With only two poles the branches go straight up and down from \(-1\): more gain means less damping, but never instability.
