Problem. A folder contains files and other folders, which contain more of both. Code that wants the total size would need to check at every level “is this a file or a folder?”.

Solution. Files and folders share one interface, Node, with size(). A file returns its own size; a folder asks each of its children and adds up. The recursion is in the folder, and the caller treats a whole tree exactly like a single file.

  1. One interface for leaves and containers.
  2. Leaves do the work themselves.
  3. Containers delegate to their children and combine the answers.

Where you meet it

File systems, GUI layouts (a panel of panels of buttons), scene graphs in games, the HTML DOM, expression trees in compilers (a sum of products of numbers).

Common mistakes

Adding container-only methods (add) to the shared interface, so leaves must implement them uselessly; and forgetting that a cycle in the tree makes the recursion endless.
