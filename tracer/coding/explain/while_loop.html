A while loop repeats as long as its condition is true, checking it before every round. It fits problems where the number of rounds is not known in advance: read until the input ends, retry until it works, divide until nothing is left.

Something in the body must eventually make the condition false, here n shrinks by a digit each round; otherwise the loop never ends (an infinite loop). A do … while loop (C++, Java, JavaScript) checks after the body instead, so it always runs at least once.

Common mistake

Forgetting the update. Without n = n // 10 the condition never changes and the program hangs. And check the edge: this program says 0 has 0 digits.

Try it

Switch to JavaScript and look at line 4: without Math.floor, n would become 409.6 and the loop would run about 330 times, until n is too small for a floating-point number and becomes 0.

This input: 4096: four rounds.

This input: 0: the condition is false at once, and the answer 0 is wrong for the number 0.
