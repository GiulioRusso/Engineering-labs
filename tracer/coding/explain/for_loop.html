Iteration repeats a block. A for loop is used when the number of rounds is known: here, once for each number from 1 to n. A variable that collects a result across rounds, like total, is created before the loop so it is not reset each time; this pattern is called an accumulator.

In the C family the loop header has three parts: start (int i = 1), condition checked before every round (i <= n), and step after every round (i++). Python’s for instead walks through the values of a sequence, and range(1, n + 1) produces 1, 2, …, n: the end value is excluded.

Common mistake

Off-by-one errors: range(1, n) stops at n − 1, and i < n instead of i <= n misses the last value. Check the first and last round by hand.
