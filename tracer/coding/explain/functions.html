A function gives a name to a piece of code so it can be used many times. It is defined once, with parameters (named inputs), and called with arguments (the actual values). return sends a result back to the caller and ends the call.

Each call gets its own frame on the call stack, holding its parameters and local variables; when the call returns, the frame disappears. Functions are how programs are broken into small, testable, reusable parts. Statically typed languages declare the parameter and return types.

Common mistake

Printing inside a function instead of returning. print(w * h) shows the value but gives the caller nothing to work with: r1 would be None.
