Variables have a scope: the part of the program where they exist. Parameters and locals belong to their call and vanish when it returns; a function cannot see or change the caller’s variables by name.

What a function receives is a copy. For a number, it is a copy of the value, so changing n leaves count alone. For a list or an object, what is copied is the reference, the arrow to it: both names point at the same list, and changes made through one are seen through the other. C++ makes this explicit: without & the whole vector is copied.

Common mistake

Expecting a function to change a caller’s number (it can’t: return the new value instead), or not expecting it to change a caller’s list (it can: copy the list first if that matters).
