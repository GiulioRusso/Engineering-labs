Every value has a type: whole numbers (integers), decimal numbers (floating point), text (strings) and true/false (booleans). The type decides how much memory the value takes and what the operators mean: + adds numbers but joins strings.

In statically typed languages (C++, Java) each variable is declared with a type that never changes, and the compiler checks every expression. In dynamically typed ones (Python, JavaScript) the value carries the type and a name can later hold something else. The classic surprise is division: with two integers C++ and Java drop the fraction (7 / 2 is 3), while Python and JavaScript give 3.5.

Common mistake

Computing an average as sum / count with two integers in C++ or Java: 7 / 2 gives 3, silently. Make one side a decimal (sum / 2.0, or a cast) first.
