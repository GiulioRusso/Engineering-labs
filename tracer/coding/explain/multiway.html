Multi-way selection: else if

What you are looking at

Left: the program, with the line just executed highlighted; switch language with the buttons above it (your choice is remembered). Right: the sentence explaining the step, the condition just tested (green true, red false), the call stack with every variable (name, type, value; yellow = just changed), any objects or lists that references point at, the output so far, and the flowchart (block diagram) of the same program: the block being executed is lit up, and a decision turns green or red with its answer. The flowchart is the same in every language; only the syntax changes. Press play, or step with the play bar; the cases at the top right run the same code on other inputs.

When there are more than two cases, conditions are chained: if … else if … else if … else. They are tested in order, and the first one that is true wins; the rest are skipped without being tested. The final else catches everything that matched nothing.

Because of this, order matters: the thresholds go from the most demanding down. Many languages also have a switch (or Python’s match) for choosing among exact values such as menu options; ranges like these are written with else if.

Common mistake

Writing separate if statements instead of else if. Then a score of 95 passes all three tests and grade is overwritten to "C" at the end. Or putting score >= 60 first: everyone who passes gets a C.

Try it

Run the three inputs and count how many conditions each one tests before a branch is taken: 1, 2 and 3.
