A string is text: a sequence of characters, indexed from 0 like a list, with a length. A loop can visit its characters one by one. Strings come with many built-in operations: find a substring, change case, split into words, replace.

In C++ and Java a single character has its own type, char, written in single quotes ('a'); Python and JavaScript have no character type, and a character is just a string of length 1.

Common mistake

Comparing strings with == in Java: it compares whether they are the same object, not the same text. Use s.equals(t).
