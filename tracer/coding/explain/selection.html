Selection lets a program choose. An if statement evaluates a condition, an expression that is either true or false, and runs its block only when it is true; the optional else block runs otherwise. Exactly one of the two runs, then execution continues after the whole statement.

Conditions are built from comparisons (==, !=, <, <=, >, >=) and combined with logical operators: and, or, not. The languages differ only in punctuation: Python marks the blocks by indentation and a colon; the C family uses parentheses round the condition and braces round each block.

Common mistake

Writing if (x = 5) in C++ or JavaScript: a single = assigns 5 and the condition is always true. Comparison is == (in JavaScript prefer ===, which does not convert types).
