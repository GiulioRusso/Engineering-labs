An array (a list in Python) stores many values under one name, one after another. Each element is reached by its index, its position counted from 0: temps[0] is the first, temps[4] the last of five. The length tells how many there are.

Searching for the largest value is the standard pattern: assume the first is the best, then compare every other element with the best so far. Arrays in C++ (std::vector), JavaScript and Python can grow; Java’s int[] has a fixed length (its growable list is ArrayList).

Common mistake

Reading one past the end, temps[5] in a list of five. Python raises an IndexError and Java an exception; C++ silently reads whatever memory is there, a famous source of bugs.
