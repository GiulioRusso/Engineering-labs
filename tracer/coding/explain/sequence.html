A program is a list of instructions carried out in order, one after another, top to bottom. This is sequence, the first of the three building blocks of every algorithm (with selection and iteration).

A variable is a named place in memory that holds one value. Assignment, written =, evaluates the right-hand side and stores the result under the name on the left; whatever was there before is overwritten. So = means “store”, not “is equal to”, and a = a + 1 makes sense. Swapping two values shows why order matters: you need a third variable to keep one value safe while the other is overwritten.

Common mistake

Writing a = b; b = a; to swap. After the first line both hold 8, and the original 5 is lost. Python can also write a, b = b, a, which builds a temporary pair for you.
