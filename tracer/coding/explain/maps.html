A dictionary (map) stores pairs: a key and its value. Instead of a position you look values up by key, such as a word, a name or an ID, and the lookup is fast however many pairs there are (it does not search one by one).

Counting things is the classic use: for each item, read its count (0 if it is not there yet), add 1, store it back. The languages differ in the details: what a missing key gives you, and whether the keys keep their order.

Common mistake

Reading a missing key: Python’s counts[k] raises KeyError (use get), JavaScript gives undefined, and C++’s counts[k] silently inserts the key.
