A class is a blueprint that bundles data, its fields, with the functions that work on that data, its methods. An object is one instance built from the class, with its own copy of the fields. The constructor (__init__ in Python) runs when the object is created and sets it up.

Inside a method, self (Python) or this (the others) refers to the object the method was called on. Keeping the rules next to the data, such as “a withdrawal cannot exceed the balance”, means every part of the program that uses an Account gets the same behaviour. This is the basis of object-oriented programming (see Design patterns).

Common mistake

Forgetting self. in Python: balance += amount would refer to a local variable that does not exist and raise an error. In JavaScript, forgetting this. has a similar effect.
