A recursive function calls itself on a smaller version of the same problem. It needs a base case that is answered directly (here 1! = 1) and a recursive case that moves towards it (n! = n × (n − 1)!).

Every call waits for the one it made, keeping its own n in its own frame, so the call stack grows with each level and then unwinds as the results come back, the last call returning first. Recursion is natural for things defined in terms of themselves: trees, folders inside folders, divide-and-conquer sorts.

Common mistake

A missing or unreachable base case: the calls never stop and the stack overflows (RecursionError in Python, a crash in C++). Also, each level costs memory: a loop is often the better choice for long chains.
